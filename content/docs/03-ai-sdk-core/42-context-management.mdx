# Context Window Management

When building conversational AI applications, message history can grow beyond the model's context window limit. The AI SDK provides a simple, functional approach to automatically select which messages to keep based on priority.

## Basic Usage

The `contextWindow` middleware automatically selects messages that fit within your token budget:

```ts
import { contextWindow, wrapLanguageModel, generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const model = wrapLanguageModel({
  model: openai('gpt-4o'),
  middleware: contextWindow({
    maxTokens: 100000,
  }),
});

// Use the model normally - context is managed automatically
const { text } = await generateText({
  model,
  messages: veryLongConversation,
});
```

By default, messages are kept based on **recency** (newer messages have higher priority), and system messages are always kept.

## Priority Functions

The core concept is simple: each message gets a priority score. Higher score = more important = kept longer.

```ts
contextWindow({
  maxTokens: 100000,
  priority: (message, { index, total, tokens }) => {
    // Return a number. Higher = more important.
    // index: position in message array (0 = oldest)
    // total: total number of messages
    // tokens: estimated tokens in this message

    if (message.role === 'system') return Infinity; // Always keep
    if (message.role === 'user') return 1000 + index;
    if (message.role === 'tool') return index;
    return 500 + index;
  },
})
```

Special values:
- `Infinity` — Always keep (pinned)
- `-Infinity` — Always drop

## Built-in Priority Helpers

For common patterns, use the built-in helpers:

### `recency` (default)

Keeps newer messages, pins system messages:

```ts
import { recency } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: recency, // This is the default
})
```

### `byRole`

Assigns priority based on message role:

```ts
import { contextWindow, byRole } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: byRole({
    system: Infinity, // Always keep
    user: 1000,
    assistant: 500,
    tool: 100,
  }),
})
```

### `pin`

Pins specific messages (always keep):

```ts
import { contextWindow, pin } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: pin(msg => msg.role === 'system'),
})
```

### `drop`

Always drops specific messages:

```ts
import { contextWindow, drop } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: drop(msg => msg.role === 'tool'),
})
```

### `boost`

Adds priority to matching messages:

```ts
import { contextWindow, boost } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: boost(msg => msg.role === 'user', 500),
})
```

### `combine`

Combines multiple priority functions:

```ts
import { contextWindow, combine, pin, boost } from 'ai';

contextWindow({
  maxTokens: 100000,
  priority: combine(
    pin(msg => msg.role === 'system'),
    boost(msg => msg.role === 'user', 500),
    (_, { index }) => index, // Add recency
  ),
})
```

## Model Presets

Use `forModel` for known models with pre-configured limits:

```ts
import { forModel, wrapLanguageModel } from 'ai';
import { openai } from '@ai-sdk/openai';

const model = wrapLanguageModel({
  model: openai('gpt-4o'),
  middleware: forModel('gpt-4o'),
});
```

Available presets include `gpt-4o`, `gpt-4o-mini`, `claude-3-5-sonnet`, `gemini-1.5-pro`, and more. Check `modelContextLimits` for the full list.

You can also customize presets:

```ts
forModel('gpt-4o', {
  priority: byRole({ user: 1000, tool: 100 }),
  onDrop: info => console.log(`Dropped ${info.count} messages`),
})
```

## Drop Notifications

Get notified when messages are dropped:

```ts
contextWindow({
  maxTokens: 100000,
  onDrop: ({ count, tokens, messages }) => {
    console.log(`Dropped ${count} messages (${tokens} tokens)`);
    // Log dropped messages for debugging
    messages.forEach(m => console.log(`  - ${m.role}`));
  },
})
```

## Custom Token Estimation

The default estimator uses character-based approximation (~3.5 chars/token). For more accuracy:

```ts
import { contextWindow, createCharacterBasedEstimator } from 'ai';
import { encoding_for_model } from 'js-tiktoken';

// Use tiktoken for accurate OpenAI token counts
const enc = encoding_for_model('gpt-4o');

contextWindow({
  maxTokens: 100000,
  estimateTokens: (message) => {
    const text = JSON.stringify(message);
    return enc.encode(text).length;
  },
})
```

## Direct Context Selection

For advanced use cases, use `selectContext` directly:

```ts
import { selectContext, byRole } from 'ai';

const result = await selectContext(messages, {
  maxTokens: 100000,
  priority: byRole({ user: 1000, tool: 100 }),
});

console.log(result.messages); // Selected messages
console.log(result.tokens);   // Total tokens used
console.log(result.dropped);  // Info about dropped messages
```

## Best Practices

1. **Start simple** — Use the default recency-based selection first
2. **Pin critical context** — System messages and key instructions should use `Infinity`
3. **Monitor drops** — Use `onDrop` to understand what's being removed
4. **Consider token estimation** — For production, consider accurate tokenizers
5. **Test edge cases** — Very long single messages, empty conversations, etc.
